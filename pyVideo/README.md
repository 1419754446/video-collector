# 视频集中整理工具（Video Collector）

一个用 **Python + PySide6** 写的桌面小工具：选中一个目录，递归找出里面所有视频，把它们**复制**或**移动**到一个统一文件夹里；顺手还能**预览播放**、把不要的视频**删除到回收站**。

适合这种场景：素材散落在十几个下载目录里，想把所有 `.mp4 / .mkv / .mov` 收拢成一个"视频库"。

界面已按 C++（WebView2）版本的设计语言重做：**三栏布局 + 深色/浅色双主题 + 自绘控件**，全局 100% 矢量绘制，高 DPI 屏不糊。两版的**功能集与快捷键保持一致**（见下方「实用小功能」）。

侧栏本身**不再放任何设置控件**：全部搜索/整理选项收进一个四步向导（点「当前设置」卡右上角的**修改**随时重开），侧栏只保留一张只读的「当前设置」摘要卡、一张「外观」卡、两条小提示，以及底部三颗按钮（**开始搜索 / 整理选中 / 取消任务**）。

## 环境要求

- Windows / macOS / Linux 均可（在 Windows 上开发和测试）
- Python 3.8+
- PySide6（必需）
- opencv-python（**可选**）：用于生成视频缩略图；不装也能正常运行，缩略图列显示占位图

```bash
pip install -r requirements.txt
# 或者只装必需项：
pip install PySide6 PySide6-Addons
```

## 运行

```bash
python video_collector.py
```

Windows 下也可以直接双击 `启动.bat`。

## 使用步骤

1. 首次启动会自动弹出**整理设置**向导（点侧栏「当前设置」卡右上角的**修改**可随时重开），四步走完即生效：
   - **① 搜索方式**：`指定目录`（选源目录）或 `全盘搜索`（只读扫描，可勾选磁盘；此时源目录整块隐藏）；
   - **② 格式与大小**：点开扩展名按钮**勾选**要的格式（24 个常用项 + 自定义），再填**体积范围**的最小 / 最大（单位 MB，留空或 0 表示这一端不限）；
   - **③ 操作方式**：**复制**（原文件保留）/ **移动**（原文件移走），以及文件重名时是 `自动重命名` 还是 `同名跳过`（不覆盖）；
   - **④ 开关**：包含子文件夹 / 跳过隐藏项 / 跳过相同视频 / 完成后打开目标。
2. 点侧栏底部的**开始搜索**。这一步**只读**：只把符合条件的视频列进表格，不复制、不移动、不删除任何文件；日志会写明「只读，不会移动或删除任何文件」。
3. 在表格里**勾选**要整理的视频（支持 Ctrl / Shift 多选，`Ctrl+A` 只选当前可见行），再点**整理选中**。只有这步才会真正写盘：移动模式会先弹一次确认（"会把源文件从原位置移走"）。列表里每个文件的状态会变成 `已复制` / `已移动` / `同名已存在，已跳过` / `失败：原因`；顶部统计胶囊同步刷新 **全部 / 成功 / 失败 / 跳过 / 已在目标 / 已删除 / 待处理 / 总体积**。
4. 缩略图按**可视行懒加载**（需要 `opencv-python`；没有则显示占位图）：屏幕上看得到的行会优先出图，滚动时再补，上万条搜索结果也不会一次性解码。完成后可以从工具条的**更多 ▾**菜单里点**导出 CSV**，得到每个文件的"从哪来 → 到哪去"清单（UTF-8 带 BOM，Excel 直接双击不乱码）；同一菜单里还有**导出报告**（自包含 HTML）和**撤销本次整理**。
5. 想看一眼视频：**双击表格里的任意一行**即可在右侧面板预览播放（**任务运行中也能播**，只有「删除」在运行中禁用）；碰到内置播放器不支持的格式（例如部分 `.mkv` / `.avi`），点**系统播放器**用本机播放器播；也可以在侧栏「外观 → 预览方式」选**独立窗口**，双击直接弹独立播放窗口。
6. 不要的视频：选中一行或多行（支持 Ctrl / Shift 多选），点**删除选中**（或按 `Delete` 键），文件会**移入 Windows 回收站**，需要时可以从回收站还原；如果该视频已经在目标文件夹里有一份副本，弹窗里可以勾选"同时删除目标副本"。
7. 中途想停：点底部**取消任务**，当前文件处理完即停。

设置（搜索方式、目录、选项、扩展名、体积范围、向导是否看过、窗口大小与分栏比例、音量、**主题**、日志/预览折叠状态、日志高度、最近使用目录、完成后自动打开）会自动记住，下次打开还是上次的样子。

## 界面设计规范（PySide6 版）

这一版界面是按"三层表面 + 字号阶梯 + 圆角分级"重搭的，不是逐控件调参，规则都写在 `app/theme.py` 里，改色改尺寸只动这一个文件。

**三层表面**（层次靠明度差和留白，不靠边框堆叠）

| 层 | 内容 | 浅色 | 深色 |
| --- | --- | --- | --- |
| 窗口底 | 纵向微渐变 | `#eff2f8 → #e9edf6` | `#0b0d12 → #080a0e` |
| 侧栏 | 白面板 + 右侧 1px 描边，里面是两张轻卡片（当前设置 / 外观）+ 一条透明提示 | `#ffffff` | `#161a21` |
| 中部卡片 | 任务列表 / 运行日志 / 预览，圆角 14 | `#ffffff` | `#161a21` |

**配色**

- 主强调 靛蓝 `#4b5cf0`，辅强调 青 `#12b6c9`，品牌渐变 `#5b6cf5 → #4b5cf0 → #12b6c9`，只用在主按钮、进度、选中态；其余一律中性灰蓝。
- 深色主题单独压深了主按钮渐变（`btn_grad_*`），保证白字对比度；进度条仍用亮一档的 `grad_*`，在深底上才够醒目。
- 语义色：成功 `#10875f` / 跳过 `#9a6408` / 失败 `#c62f47`，各自配一张 `*_soft` 淡底给药丸和胶囊用。
- 分隔线统一 `divider`，不用 `border` 画内部分隔，否则卡片里会出现一圈"方角灰杠"。

**字号阶梯**（彻底取消 10px 档；基础字重 500，强调处 600/700）

| 用途 | 字号 | 字重 |
| --- | --- | --- |
| 品牌标题 | 20 | 700 |
| 卡片标题 / 字段标签 | 12 / 12.5 | 600 / DemiBold |
| 正文 | 13 | 500 |
| 说明文字（副标题、提示） | 12 | 600 |
| 舞台占位标题 / 空状态标题 | 13 / 15 | 600 |
| 日志计数 | 11 | 600 |
| 播放进度百分比 | `QFont("Consolas", 10)` | 常规 |

> 微软雅黑上 `font-weight: 500` 会回落到常规体，对控件几乎零效果；要视觉上真的变粗得写 600，这条已经统一到 QSS 里。

**圆角与几何**

- 圆角：卡片 14 / 输入框与按钮 10 / 分段槽 12 / 分段药丸 9 / 菜单 10 / 快捷键 Kbd 5。
- 侧栏 320px，内边距 `(16,14,16,12)`，间距 10；主区边距 `(22,20,22,18)`，间距 14。
- 主按钮高 46、次按钮与工具条 36、输入组 36；表格行高 68、缩略图列 104、列宽 序号 48 / 大小 88 / 状态 118 / 来源文件夹 142（窗口 ≥1360 时预览列 420，窄窗口收到 322，把宽度让给文件名列）。
- 状态列只画**短标签**（已复制 / 已移动 / 已跳过 / 失败 / 已在目标 / 已删除 / 待处理），完整原因放在行的 tooltip、预览面板、运行日志与导出报告里——148px 的药丸里塞「失败：大小校验不通过（1.2 GB ≠ 1.5 GB）」只会被省略号糊掉。
- 预览面板最窄 322、最宽 420，舞台区（视频画面）吃掉剩余高度，底部信息不再留空洞。

**自绘控件**

分段控件（白药丸 + 两圈极淡投影）、开关（40×22，开启态品牌对角渐变）、统计胶囊（双色语义底 + 选中反转为实心强调色）、6px 三段渐变进度条、状态药丸（圆点做第二重编码 + 选中行左侧 3px 强调条）、空状态插画（三张错位叠放的小卡片）、`AutoHideLabel`（空内容自动隐藏，日志/预览面板靠它消除空白）。

新增带自绘的控件必须实现 `apply_theme()`，否则切换主题时不会重刷颜色（`MainWindow._apply_theme` 会遍历 `findChildren(QWidget)` 逐个调用）。

## 实用小功能（两版一致）

| 功能 | 怎么用 |
| --- | --- |
| **状态快捷筛选** | 点击顶部统计胶囊（成功 / 失败 / 跳过 / 已在目标 / 已删除 / 待处理）只看这一类，例如「仅看失败」；再点一次或点「全部」/ 按 `Esc` 取消。侧栏底部会显示「显示 x / y」 |
| **交换源/目标** | 向导第①步「源目录」标题右侧的 ⇄ 按钮，一键互换源与目标（填反了或想反向整理时很方便） |
| **最近使用目录** | 向导里源目录 / 目标输入框旁的时钟按钮，列出最近 6 个用过的路径，可一键回填或清空，搜索开始时自动记录 |
| **完成后打开目标** | 向导第④步的开关，任务正常结束且有成功项时自动打开目标文件夹；取消或出错不会触发 |
| **快捷键说明** | 工具条 `?` 按钮或 `F1`，两版显示同一份快捷键与操作提示 |
| **更多菜单** | 工具条的「更多 ▾」里放**导出 CSV / 导出报告 / 撤销本次整理**：这几个都是低频操作，收进菜单后窄窗口下工具栏不会被挤爆（两版菜单项完全一致） |
| **窄窗口自适应** | 窗口变窄时优先保证列表可读：C++ 版自动收起右侧预览列（右下角悬浮按钮可临时展开），Python 版做三件事——主区宽度不足 980 时把「删除选中 / 打开目标」收进「更多 ▾」菜单、预览列从 420 收到 322、文件名列不足 140px 时收起「来源文件夹」列；统计胶囊改成按宽度自动换行（`FlowRow`），窗口压到 1280×720 也不会被裁掉半截 |
| **预览方式联动** | 侧栏「外观 → 预览方式」选**独立窗口**时，右侧预览列自动收起（视频在独立窗口里播，不留一条空栏占 344px），**下次启动也按这个模式直接收起**；切回「侧栏内」自动展开，右下角悬浮按钮可临时展开看文件信息 |

**筛选的数据安全约定**：文字筛选和状态筛选可叠加；被隐藏的行会自动取消选中，`Ctrl+A` 与「删除选中」都只作用于**当前可见行**，绝不会误删看不见的文件。这一点在两版中行为一致。

## 全盘搜索（只读）

向导第①步把搜索方式切成**全盘搜索**后，点侧栏「开始搜索」：

1. 弹出的对话框里**手动勾选要搜的磁盘**（默认一个都不勾，网络盘 / 光驱不可选）；可加自定义排除目录、设置结果上限（默认 20000）。
2. 确认后进入**只读**阶段：不会复制、移动、重命名、删除任何文件，也不建文件夹。系统目录、隐藏项、链接目录、目标文件夹及其子路径会自动跳过；单目录读不动只记日志继续；随时可「取消任务」。进度显示「已扫描 N 个目录 · 发现 M 个视频」，不伪造百分比。
3. 结果直接进任务列表，可用文字筛选 / 状态胶囊筛选；`Ctrl+A` 全选**可见行**后点「**整理选中**」，把勾选的视频统一复制 / 移动到目标文件夹。

同理，「指定目录」模式点「开始搜索」也只是扫描该目录（跟随「包含子文件夹」开关），同样要勾选后才写盘。

「整理选中」不会重新扫描，而是把选中行的完整路径直接交给原有整理链路，所以**去重、同名处理、移动后大小校验、回收站删除、取消语义全部不变**；状态回写到原来的行上，不会插出重复行。搜索与整理共用同一个后台任务槽，互斥运行。

两端行为一致：Python 用 `app/scan_all.py` 的 `ScanAllWorker(QThread)`（新增 `recursive` 参数，指定目录搜索也复用它），C++ 用 `CollectorJob` 的 `scanOnly` 多根扫描 + `start_files` 命令；盘符列表由原生侧枚举（Win32 `GetLogicalDrives` / `GetDriveTypeW`），参数分别存在 QSettings 与 `config.json`。

| 目录输入框旁的 ⇄ / 时钟 | 交换源与目标 / 选最近使用过的目录（在向导第①步里） |
| 全盘搜索 | 在向导第①步选「全盘搜索」，再点「开始搜索」，勾选结果后统一放到目标文件夹 |
| 点击预览区路径 | 复制完整路径 |
| 日志标题行 / 顶部细条 | 点击折叠展开 / 上下拖拽调整高度（120~420px，会记住） |

- 表格支持点表头排序（按大小是真实字节数排序），状态列显示为彩色**药丸标签**。
- 表格是 **Model/View 架构**（`app/table_model.py`）：数据只存在 `MainWindow.rows` 一份，`VideoTableModel` 按列现取现格式化，`VideoFilterProxy` 负责关键字/状态筛选与排序。两万行上限下不再为每格创建 `QTableWidgetItem`，排序不重排控件、筛选不逐行开关隐藏，滚动与刷新都是 O(可视行)。
- 行定位内部统一使用稳定 UID：`uid → 行号` 由代理模型 `mapFromSource/mapToSource` 现算，排序、筛选、删除、缩略图回填都不会写错行。
- 新增行做了**批量插入**（攒一小批一次性 `beginInsertRows` 插模型），几千个文件也不会卡住界面。
- 状态回写只对那一行的状态格发 `dataChanged`，不再整表刷新。

## 关键行为说明

| 情况 | 工具怎么处理 |
| --- | --- |
| 不同子目录里有同名视频 | 默认自动重命名：`video1.mp4`、`video1 (1).mp4`、`video1 (2).mp4`…（也可选"同名跳过"） |
| 重复跑同一个任务 | 默认开启去重：目标里若已有同名（含 `(1)` 系列）且**大小 + 首/中/尾各 64KB 内容一致**的文件，直接跳过，不会复制出一堆副本 |
| 视频体积不在设定范围 | 向导第②步「体积范围」的单位是 **MB**，任一端留空或填 `0` 表示这一端不限；搜索（含全盘）在列举阶段就不收录（不占表格行），整理已选中的条目时则标记`跳过：体积不在范围`（黄色药丸），不会中断任务 |
| 目标文件夹就在源目录里面 | 扫描时自动跳过目标目录本身，不会"自己收集自己" |
| 文件本来就在目标文件夹里 | 标记为`已在目标目录`，不做任何操作 |
| 复制完成后 | 校验目标文件大小与原文件一致，不一致按失败处理并清理残缺文件 |
| 中途点取消 | 当前文件处理完就停，已处理的保留，未处理的标记保持`排队中` |
| 单个文件出错（被占用、权限、路径过长） | 记录为`失败：原因`并继续处理下一个，不会中断整个任务 |
| 任务进行中 | 预览 / 播放 / 独立窗口 / 系统播放器照常可用（双击就能看片），只有**删除选中**禁用；移动模式下若源文件正被播放器占用，复制/移动会等待并自动重试，仍不行就报`失败：文件正被占用…`并继续下一个 |
| 视频已被删除 | 缩略信息仍在表格里保留（状态改为`已删除源文件` / `已删除源文件和目标副本`），报告里也会体现 |

删除的安全约定：

- 默认走 **Windows 回收站**（`SHFileOperation`，带"允许撤销"标志），不是永久删除；回收站不可用（例如网络盘）时会报错，不会偷偷改成永久删除。
- 删除前会弹窗确认，默认按钮是「取消」。
- 任务运行中禁止删除，避免和复制/移动抢同一个文件。

## 应用图标

图标不是随手塞一张 png，而是按 Windows 各处的实际取用规则做的：

- **一套几何、九个尺寸**：仓库根目录的 `tools/make_app_icon.py` 用同一套矢量几何（圆角方块 + 品牌渐变 `#6b6bef → #4f8dff → #12b6c9` + 播放三角）渲染 16/20/24/32/40/48/64/128/256 九个尺寸，同时输出 `app.ico`、`app.png`(512) 与 `app.svg`，并一起写入 `pyVideo/assets` 和 `VideoCollectorWeb/res`——两个版本的图标因此永远一致。
- **小尺寸单独优化**：16/20/24 用更大的三角占比、更小的圆角、更压缩的渐变色阶，避免缩放糊成一团。
- **运行时代码**：`app/utils.py` 的 `resource_path()` 同时兼容源码运行和 PyInstaller 的 `_MEIPASS` 布局；`app_icon()` 优先用 `app.ico`（Qt 会按标题栏/任务栏需要的尺寸自己挑图层），找不到才退 `app.png`。
- **生效范围**：`QApplication.setWindowIcon()`（对话框、消息框等兜底）、主窗口、独立预览窗口都设了图标；界面左上角的品牌标（`LogoBadge`）也直接绘制这份图标，不再单独画一套图形。Windows 上另用 `SetCurrentProcessExplicitAppUserModelID` 绑定任务栏身份，源码运行时任务栏也不会显示成 Python 的图标。C++ 版侧栏内嵌的是同一份 SVG，因此两版界面左上角的标志、窗口图标、exe 图标完全一致。
- **改图标**：改完颜色或形状直接 `python tools/make_app_icon.py` 重跑，两端资源同步更新，不用手工替换文件。

## 想打包成 exe

```bash
pip install pyinstaller
pyinstaller VideoCollector.spec --noconfirm
```

生成在 `dist\VideoCollector.exe`，可以脱离 Python 环境拷给别人用。`VideoCollector.spec` 已配置单文件、无控制台，并在 `hiddenimports` 里声明了 `cv2`；若构建环境装了 opencv，exe 约 110MB，缩略图在别的电脑上也能正常生成，没装则约 40MB+、缩略图列显示占位图。

打包注意三点（已在 spec 里处理好）：`icon=` 用相对路径 `assets/app.ico`，换台机器也能直接打包；`datas=` 把 `assets/` 一起打进包里，否则 exe 运行后窗口和任务栏图标会退化成 Windows 默认图标（代码靠 `resource_path()` 在 `_MEIPASS` 下读 `assets/app.ico`）；`version='version_info.txt'` 给 exe 写入产品名/版本号（不写的话「属性 → 详细信息」全是空的，SmartScreen 更容易拦）。

## 已知限制

- **缩略图依赖 opencv-python**：未安装时不会报错，缩略图列显示占位图；部分编码（如老式 `.rmvb`）可能取不到首帧，同样保留占位图。

## 缩略图缓存

首帧缩略图缓存在 `~/.videocollector/thumbnails/`（每张几十 KB，失败文件会留一个 `.nop` 记号，避免反复重试坏文件）。

- **内存**：模型层最多保留 400 张 `QPixmap`（LRU 淘汰最久未用），两万行也不会把显存/内存吃满。
- **磁盘**：默认上限 **256 MB**，超了就按 mtime 做 LRU 清理（读取时 touch 一次，最久没打开的缓存先删）。启动后自动巡检一次，缩略图加载空闲时也会顺手检查（内部 60s 节流）。
- **手动清空**：工具条「**更多 ▾**」→「清空缩略图缓存（当前占用）」，确认后删除全部缓存图片；只删缓存，不动视频文件，下次浏览会重新生成。
- 上限值存在 `QSettings` 的 `thumb_cache_mb`（默认 256，最小 32）。

- **只按扩展名识别视频**，不解析文件头：改了后缀的假视频也会被收进来；要更严格可以自己把扩展名列表改短。
- 内置预览用的是 Qt 的 Windows 多媒体后端（Media Foundation / DirectShow）：`.mp4 / .mov / .wmv / .avi` 一般没问题，部分 `.mkv / .rmvb / .ts` 可能打不开，此时请用「系统播放器」或「独立窗口」。
- 不做转码、不重命名内容、不按日期分文件夹——它的职责就是把文件搬到位。
- **超长路径**（整体超过 260 字符）：只要 Windows 开启了长路径支持（Win10 1607+ 的 `LongPathsEnabled`，本机即已开启），两版都能直接处理——C++ 版在 exe 清单里声明了 `longPathAware`，Python 版由 CPython / PyInstaller 的清单提供同一标志，所以**不需要**在路径里拼 `\\?\` 前缀（那个前缀会让回收站 `SHFileOperationW`、Shell 打开/定位和路径比较全部失效）。系统未开启时会按失败处理并在表格里写明原因；开启方式：`reg add HKLM\SYSTEM\CurrentControlSet\Control\FileSystem /v LongPathsEnabled /t REG_DWORD /d 1`，重启后生效。
- 全盘搜索不按内容语义分类（电影 / 剧集 / 教程），也不解析视频元数据；它只按扩展名发现文件，再由用户勾选后统一归置到一个目标文件夹。
- 去重指纹是「快速去重」而非密码学校验：采样首、中、尾各 64KB（小文件整读），仍属概率判重——两个大小与这三段都相同、只有其它位置不同的视频会被判为重复而跳过。对可疑的重复项建议临时关闭「跳过相同视频」再跑一次。
- 移动模式下文件是"剪切"（不是 Windows 可撤销操作）；需要回退时用「更多 → 撤销本次整理」，它只处理**最近一次**整理、且目标副本仍存在时才能移回源位置，不确定时先用复制模式试一遍。
- 网络盘 / 移动硬盘断连会导致对应文件失败并记录错误，不影响其余文件。
- 删除走 Windows 回收站；在 macOS / Linux 上是直接删除（同样有确认弹窗）。
